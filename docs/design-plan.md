# 《恐龙冲击》设计差距分析与修改方案

> 依据：《恐龙冲击》设计草案（冯嘉杰、贺保顺，2026.11）
> 对照代码：`Assets/StreamingAssets/Lua/dino_*.lua`（Lua 玩法层）+ `Assets/SurfImpact/Scripts`（C# 宿主层）
> 本文档为实施参考，章节号（1.2.x）均指设计草案原文。

---

## 一、总览

当前代码是一个**模拟量操控的地面奔跑原型**：W/S 控制前后油门、A/D 横向平移（带惯性与倾斜），碰到任何障碍即一次死亡；地图上只有石頭/木头/灌木/蛋。

设计文档描述的是一个完整得多的游戏：**五档朝向的离散操控 + 3 点生命 + 射箭 + 六类障碍效果 + 干扰型恐龙 + 可驾驭恐龙与技能**。两者的核心循环（"自动前进、躲障碍、吃蛋"）一致，因此现有骨架（无尽平原生成、实体/相机/UI/音频 API、fx 震动/顿帧、占位像素画、无头测试）全部可复用，需要重写与新增的是玩法系统本身。

- `fx.lua` 顿帧/震屏/粒子/延时回调；`Host.ui` 全部 HUD/菜单 API；`Host.entity` 精灵管理；

- `tools/luatest/dino_tests.lua` + `mock_host.lua` 无头测试框架。

## 三、需要先拍板的设计疑点

1. **没有跳跃键。** 文档多处写"矮，可被跳过"，但按键汇总（A/D/W/S/J/Space）里没有跳跃。两个方案：
   - ① 新增跳跃键（建议左 Shift，或双击 W）；
   - ② **基础恐龙不会跳**，"可跳过"只对暴龙幼崽/驰龙的跳跃技能与弹簧草跳板生效（文档本来就给了这两类跳跃来源，改动最小，推荐）。
2. **Space 键冲突。** Space 现在是菜单确认/暂停键。建议：游戏中 Space=恐龙技能；暂停只用 Esc/P；菜单里 Space 仍作确认。
3. **弓箭细节（文档留白"你来定"）**：开局带几支箭（建议 3）、CD 时长（建议 ~0.6s）、箭射程。全部进 `dino_config.lua` 可调。
4. **前进速度模型。** "不断的行进"意味着基础速度自动。建议：固定巡航速度 + 随距离缓慢提速（难度曲线），减速/加速障碍与似鸟龙冲刺都实现为该速度的倍率。
5. **时长类留白参数**：减速/加速/混乱持续、暴龙追逐消失时间、无敌帧时长等，统一放 `dino_config.lua` 数据表，方便调。
6. **转向型障碍"中→随机非中"**：建议随机权重偏向微左/微右（直接给"左/右"在窄障碍下太惩罚）。

## 五、分阶段实施计划（游戏 jam 节奏，每阶段结束都可玩、可测）

### P0 — 操控与生命循环（地基，先做先验证手感）

- `dino_player.lua` 重写为文档 1.2.1：五档朝向 + 自动前进（A/D 逐档、W 回中、非中保持朝向行进）；
- 3 点 HP + 无敌帧 + "受击停止前进、按 A/W/D 恢复并产生相应转向"（1.2.2 原文行为）；
- 障碍碰撞由"即死"改为"扣 1 血"；HP 归零才 GAME OVER；结算/原因文案更新；
- C# 输入暂不动（S 先空置，P2 再接射击）。
- **验收**：测试覆盖朝向状态机与 HP/无敌全流程；实际跑一局验证离散转向手感。

### P1 — 障碍效果类 + 道具（约 1 天）

- 六类障碍效果落地：阻拦（小石块/大石块/横放倒树/纵放倒树/立树/睡觉恐龙，带"可跳/不可跳"高度字段，见疑点 1）、减速（草丛、脚印坑）、加速（泥潭，"脚下打滑猛然加速"）、转向（灌木丛）、混乱（蘑菇丛：按键对调 + 头顶星星特效）、跳板（弹簧草：滞空期间无视一切障碍）；
- 道具：能量果实（周围通常伴较多障碍）、生命果实（同上）、蛋新增多边形阵列；
- 占位画新增：树/倒木/泥潭/草丛/脚印/蘑菇/弹簧草/两种果实。
- **验收**：每种效果有 debug 强制触发钩子 + 对应测试。

### P2 — 射箭 + 基础干扰龙（约 1~2 天）

- S 射箭：库存 ≤3、CD、沿当前朝向飞行、命中判定；
- 先做有防御值的三种：闲逛似鸟龙（1 箭；横移/斜移、连绵一排留缺口）、冲锋三角龙（2 箭；纵向偏玩家冲锋、成群冲锋）、张扬驰龙（1 箭；羽毛子弹、正面挡路挑衅、靠近障碍绕开）；
- 击杀计数进结算与 HUD；
- 追逐暴龙（不可射杀、越追越快、超时消失、撞障碍停追、吞其他障碍龙、追上=结束）——事件感最强，如时间紧张可后移到 P4。

### P3 — 骑乘与技能（约 1~2 天）

- 睡觉恐龙换乘流：Zzz 标识 → 靠近且朝对 → 绳索提示 → J 跳上；原恐龙惊醒前跑、旧骑乘龙留原地退出视野（1.2.7 疯狂动物园式）；
- Space 技能框架：每龙技能次数、能量果实/换乘重置、HUD 头像 + 右下角计数；
- 技能实施顺序（由易到难）：
  1. 似鸟龙-加速（期间只免阻拦类，其余正常受伤）；
  2. 三角龙 / 甲龙-短时无敌（仍会被追逐暴龙、蜥脚类击杀）；
  3. 翼龙-起飞高空（全程无敌，落地前无视障碍；平时也在地上跑）；
  4. 暴龙幼崽-跳跃 + 被动近身吞噬（10 次）；
  5. 驰龙-跳跃 + 被动扇形羽毛弹幕（10 次，内置 CD）；
  6. 鸭嘴龙-2 崽护盾（-1 生命改为 -1 崽被弹飞；崽无法挡暴龙/蜥脚类；能量果实重置为 2）。

### P4 — 大恐龙、结算与打磨（约 1 天）

- 路过蜥脚类：只见腿 + 落脚前双影前摇（先到大影子）、踩到=游戏结束、镜头晃动登场；
- 拉屎翼龙：翼影掠过 → 大便影子一排（先到的大）→ 一串落下，命中 -1，可转向往避；
- 结算四行：行进距离 / 收集蛋数 / 击杀恐龙数 / 驾驭恐龙数；HUD 对应计数器；
- 美术替换 pass：用 `DinoPixelArt` 同名机制换入真实像素画。

## 七、风险与建议

1. **P0 是整个手感的地台**（模拟量→离散五档是体验层面的大改），建议先做半天实跑验证，再铺开 P1–P4；
2. 疑点 1（跳跃）与疑点 2（Space 冲突）需在 P1 开工前拍板；
3. 追逐暴龙、蜥脚类、翼龙这三个"不可射杀"事件型敌人最花时间，属于第二梯队，砍单时优先保 P0–P3 的完整循环；
4. 所有"你来定"参数集中到 `dino_config.lua` / `dino_data.lua`，避免数值改动散落各处。
